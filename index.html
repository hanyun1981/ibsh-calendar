Admin Settings — admin teacher sign-in管理員設定：行政教師登入資訊

Set each group's holder and password. When signing in, choosing a group fills in the holder — only the password is needed.設定各組的負責人與密碼；行政教師登入時選擇組別，負責人會自動帶入，只要輸入密碼。每學年職務異動時在此修改後按「儲存」，所有人立即生效。密碼留空表示不變更；新組別若未設定密碼，會沿用目前的共用通行碼。

Admin Staff行政職員

Each staff member has a personal account with the same rights as admin teachers. Their department is filled in automatically when they post.每位行政職員一個帳號，權限與行政教師相同。處室（學務處／教務處／輔導室）會在發布時自動帶入。新增或刪除後請按「儲存」。
